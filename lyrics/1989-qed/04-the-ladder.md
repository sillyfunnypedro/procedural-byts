## The lesson

Mathematical induction proves a statement for every n ≥ 1 with two pieces: the base case (it’s true for 1) and the inductive step (if it’s true for n, it’s true for n + 1). Strong induction assumes every earlier case. Recursion, from CS1’s Base Case, has exactly the same shape. Example: 1 + 2 + … + n = n(n + 1)/2.
