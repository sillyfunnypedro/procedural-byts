## The lesson

An implication P → Q is false only when P is true and Q is false; when P is false, the implication is true no matter what (vacuously true). The converse, Q → P, is not the same statement, but the contrapositive, not Q → not P, is. The biconditional P ↔ Q, “if and only if,” is true when both sides have the same truth value.
