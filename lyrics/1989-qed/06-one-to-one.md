## The lesson

A function maps every input in its domain to exactly one output in its codomain. It’s injective (one-to-one) if different inputs always give different outputs, surjective (onto) if every possible output is hit, and bijective if it’s both, which means it can be reversed. A relation is any set of pairs; an equivalence relation (reflexive, symmetric and transitive) splits a set into classes.
