## The lesson

A graph is a set of vertices joined by edges, and a vertex’s degree is how many edges touch it. A connected graph has a path crossing every edge exactly once (an Euler path) only if it has zero or two vertices of odd degree; Königsberg had four, so the walk was impossible. Trees are connected graphs with no cycles. Breadth-first and depth-first search explore graphs, and shortest-path algorithms like Dijkstra’s find the cheapest route.
