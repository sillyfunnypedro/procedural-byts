## The lesson

A transaction groups several operations into one unit of work, with four guarantees known as ACID. Atomicity: all of it happens or none of it does. Consistency: it moves the database from one valid state to another. Isolation: transactions running at the same time don’t see each other’s half-finished work. Durability: once committed, changes survive crashes. BEGIN starts a transaction, COMMIT makes it permanent, and ROLLBACK undoes it.
