## The lesson

Without an index, a query may have to read every row in the table, a full table scan. An index, usually a B-tree, keeps the keys sorted in a wide, shallow tree, so a lookup takes only a few steps. Indexes make reads faster but writes slower, and they take up space, so index the columns you actually search on.
