## The lesson

NULL marks a missing or unknown value. It isn’t zero and it isn’t an empty string. SQL uses three-valued logic, so comparing anything with NULL gives UNKNOWN, which means NULL = NULL is not true, and WHERE only keeps rows that are TRUE. Test for it with IS NULL or IS NOT NULL. Most aggregates skip NULLs.
