## The lesson

Screens mix light, not paint, so color is additive: red, green and blue (RGB) combine to make every color, with all three at full brightness giving white and none giving black. A common format uses 8 bits per channel, values from 0 to 255, for about 16.7 million colors. The framebuffer holds a color for every pixel; resolution is how many pixels there are, and color depth is how many bits each one gets.
