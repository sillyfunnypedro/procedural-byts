## The lesson

Texture mapping adds detail by wrapping an image around geometry. Each vertex gets texture coordinates, u and v, which are blended across the triangle so every pixel knows where to sample the image. Seen from far away, a texture can shimmer because too much of it squeezes into each pixel, so mipmapping stores smaller, pre-filtered copies and picks the size that fits.
