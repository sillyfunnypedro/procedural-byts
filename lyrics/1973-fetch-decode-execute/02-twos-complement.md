## The lesson

Integers are stored in binary, each bit a power of two. Two’s complement stores negatives: flip every bit and add one. The top bit is the sign, an 8-bit signed value runs from −128 to 127, and going past the top wraps around (overflow). Hexadecimal packs four bits into each digit.
