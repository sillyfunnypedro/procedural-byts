## The lesson

A compiler translates a whole program into machine code before it runs, so it executes fast and catches many errors early. An interpreter runs code directly, statement by statement, so it’s quicker to change but slower to run. Many languages take the middle path: compile to bytecode and run it on a virtual machine.
