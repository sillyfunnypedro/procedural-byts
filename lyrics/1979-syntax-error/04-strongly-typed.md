## The lesson

A type system classifies values and stops invalid operations. Static typing checks types at compile time (as in Java and C); dynamic typing checks them while the program runs (as in Python). Strong typing refuses to mix types silently, while weak typing quietly converts them. Type inference lets the compiler work out types you didn’t write.
