## The lesson

Scope is where a name can be seen. With lexical (static) scope, which most languages use, a name refers to the nearest enclosing declaration in the source text, searching outward to the global level. An inner declaration with the same name shadows the outer one. Dynamic scope looks names up through the chain of calls instead.
