## The lesson

Functional programming treats functions as first-class values: they can be stored in variables, passed as arguments and returned from other functions. A lambda is an anonymous function, like x -> x * x. Functions that take or return functions are called higher-order. Lambda calculus, from Alonzo Church, is the theory underneath.
