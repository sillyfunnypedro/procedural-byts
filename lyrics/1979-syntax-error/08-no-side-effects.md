## The lesson

A pure function’s result depends only on its inputs, and it causes no side effects: no printing, no changing variables, no input or output. You can replace any call with its result (referential transparency), which makes code easier to test, reason about and run in parallel. Real programs still need effects, so functional style pushes them to the edges.
