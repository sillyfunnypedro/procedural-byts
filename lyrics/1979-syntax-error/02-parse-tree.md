## The lesson

A parser checks tokens against a grammar (often written in BNF) and builds a parse tree or abstract syntax tree. The grammar encodes structure like operator precedence. A syntax error means the code doesn’t fit the grammar. Syntax is form and semantics is meaning: code can parse perfectly and still be wrong.
