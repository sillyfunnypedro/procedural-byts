## The lesson

Programming paradigms are different ways of thinking: imperative or procedural (steps that change state), object-oriented (objects with state and behavior), functional (pure functions and immutable data), logic (state facts and rules, as in Prolog) and event-driven (respond to events). Imperative code says how; declarative code says what. Most modern languages mix several.
