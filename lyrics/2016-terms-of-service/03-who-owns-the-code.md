## The lesson

Software is protected in several ways. Copyright covers the specific code as written, automatically. Patents cover new inventions or methods, though software patents are controversial. Trade secrets protect confidential know-how, and licenses grant permission to use something. Work you create as an employee is usually “work for hire,” owned by your employer, so read the contract before you sign it.
