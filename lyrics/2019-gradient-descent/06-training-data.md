## The lesson

Machine learning finds patterns in data instead of following rules someone wrote. In supervised learning, each training example has features (measurements) and a label (the right answer). Classification predicts a category, like cat or dog; regression predicts a number, like a price. A model is a mirror of its data: if the training data is skewed or biased, the model will be too. Garbage in, garbage out.
