## The lesson

Symmetric encryption uses one shared secret key both to turn readable plaintext into scrambled ciphertext and to turn it back. The algorithm can be public; only the key has to be secret (Kerckhoffs’s principle), and it must be long enough that trying every key is hopeless. The hard part is getting the key to the other person safely.
