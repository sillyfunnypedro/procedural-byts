## The lesson

Passwords should be long, unpredictable (passphrases help) and different for every site, because reusing one lets a single breach unlock everything. Servers should never store the passwords themselves, only salted hashes made with slow password-hashing functions, so a stolen database can’t easily be reversed. Attackers always try dictionary words and previously leaked passwords first.
