## The lesson

Latency is how long one operation or message takes, the time until the first byte arrives. Throughput is how much gets done per second. As a rough scale, a cache answers in nanoseconds, main memory in about a hundred, storage in micro- to milliseconds, and a network round trip across a continent in tens to hundreds of milliseconds, limited by the speed of light. You can buy more bandwidth, but latency mostly has to be designed around, by moving data closer.
