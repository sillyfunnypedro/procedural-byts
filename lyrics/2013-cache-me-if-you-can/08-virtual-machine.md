## The lesson

Virtualization runs several virtual machines on one physical computer. A hypervisor underneath divides up the CPU, memory and devices and keeps the machines isolated from each other, and each one runs its own operating system. Virtual machines use hardware more efficiently and can be snapshotted, copied and moved between hosts, at the cost of some overhead.
