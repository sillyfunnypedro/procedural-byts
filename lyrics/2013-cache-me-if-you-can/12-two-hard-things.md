## The lesson

A famous joke, usually credited to Phil Karlton, says there are only two hard things in computer science: cache invalidation and naming things. People like to add a third: off-by-one errors. Cache invalidation is hard because cached copies go stale when the original changes; the usual fixes are expiring copies after a set time or telling caches explicitly when something has changed. Good names are what make a system understandable.
