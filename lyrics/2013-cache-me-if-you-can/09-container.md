## The lesson

Containers, made popular by Docker in 2013, package a program together with its libraries and settings and run it as an isolated process that shares the host’s operating system kernel. They’re much lighter and start much faster than virtual machines, which each run a whole operating system, but the isolation is weaker. They make software run the same way on every machine.
