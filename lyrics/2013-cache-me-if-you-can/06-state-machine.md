## The lesson

Many systems are best described as state machines: a fixed set of states, events that happen, and allowed transitions between states. Traffic lights, vending machines, network protocols like TCP, parsers and app screens all work this way. Drawing the states and arrows makes behavior explicit and exposes missing or impossible cases.
