## The lesson

Concurrency means structuring a program as several tasks that can make progress independently, even if one core is taking turns between them. Parallelism means actually running them at the same moment on several cores. Around 2001 to 2005, heat and power limits ended the race for faster clock speeds, so chips started adding cores instead, and software has to run in parallel to get faster.
