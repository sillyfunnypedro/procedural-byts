## The lesson

A file system organizes data into files and nested directories starting from a root, named by paths. Metadata (in Unix, an inode) records where a file’s blocks are, its size and its permissions: read, write and execute for the owner, the group and everyone else. Unix even treats devices as files, so one open/read/write/close interface works for everything.
