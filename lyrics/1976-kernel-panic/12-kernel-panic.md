## The lesson

A kernel panic is a fatal error inside the operating system kernel itself. Nothing runs above the kernel to recover it, so it halts, often saving a memory dump for debugging, and the machine has to reboot. That’s why kernel code has to be especially careful: a bug there takes everything down.
