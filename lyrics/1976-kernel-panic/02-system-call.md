## The lesson

Programs run in user mode with limited privileges, and the kernel runs in kernel mode with full access to the hardware. A system call (like read, write, open or fork) traps into the kernel, which checks the request, does the privileged work and returns. This protection stops one program from crashing or spying on the others.
