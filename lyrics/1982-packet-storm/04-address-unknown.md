## The lesson

An IPv4 address is a 32-bit number written as four numbers separated by dots. Part of it identifies the network and the rest identifies the host. A port number picks which program on that host gets the data, and an address plus a port makes a socket; a connection joins two sockets. 127.0.0.1 always means “this machine.”
