## The lesson

People use names, and networks use numeric addresses. Early on, every machine kept one shared hosts file listing every other machine, which couldn’t keep up as the network grew. The Domain Name System, introduced in 1983 and 1984, is a distributed, hierarchical directory: a lookup starts at the root, is pointed down through the domains to an authoritative answer, and the result is cached for a while.
