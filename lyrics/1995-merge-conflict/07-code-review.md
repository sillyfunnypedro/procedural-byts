## The lesson

In code review, teammates read a change before it’s merged. It catches bugs, improves clarity and spreads knowledge around the team. Good reviews check that the code is correct, tested, readable and well designed, and they comment on the code, not the person. “Looks good to me” only means something if you actually read it.
