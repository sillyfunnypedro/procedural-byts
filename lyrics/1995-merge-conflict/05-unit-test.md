## The lesson

A unit test checks one small piece of code, like a function or a class, on its own: give it an input and assert the expected output. Automated tests run after every change. Test-driven development writes a failing test first, then just enough code to pass it, then cleans up: red, green, refactor. Always test the edge cases: empty, zero, null and the boundaries.
