## The lesson

A regression is a bug in something that used to work, often caused by a change somewhere else. Regression testing reruns the whole existing test suite after every change, ideally automatically. The levels of testing are unit (one piece), integration (pieces working together), system (the whole thing) and acceptance (does it meet the users’ needs). Every fixed bug should get a test so it stays fixed.
