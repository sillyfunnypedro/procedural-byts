## The lesson

Web pages separate three jobs. HTML gives the page its structure and meaning: headings, paragraphs, links. CSS controls how it looks: colors, fonts, layout. JavaScript adds behavior: responding to clicks and updating the page. Keeping the three apart makes pages easier to change and more accessible.
