## The lesson

Web APIs let programs talk to each other over HTTP. In the REST style (Roy Fielding, 2000), data is modeled as resources with addresses, changed with the same few methods (GET, POST, PUT, DELETE), usually exchanging JSON. Each request is stateless: it carries everything the server needs, so any server can answer it, which makes it easy to add more servers.
