## The lesson

An entity component system (ECS) is an architecture common in game engines. Entities are just ID numbers. Components are plain data attached to them, like position, velocity or health. Systems run the logic over every entity that has the components they need, so a movement system moves everything with a position and a velocity. It favors composition over deep inheritance trees, and storing components in tightly packed arrays makes it fast.
