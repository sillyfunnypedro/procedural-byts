## The lesson

Games run in a game loop: read the player’s input, update the game world (physics, enemies, scores), render the frame, and repeat, typically 30 to 60 or more times a second. Moving things by delta time, the time since the last frame, keeps the game the same speed on fast and slow machines. Many engines run physics at a fixed timestep for stability and render as often as they can.
