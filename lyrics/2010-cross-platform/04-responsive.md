## The lesson

Responsive web design makes one page adapt to any screen size using flexible grids, images that scale, and CSS media queries that change the layout at different widths. Ethan Marcotte named the approach in 2010. Mobile-first design starts with the smallest screen and the essentials, then adds more layout as the screen gets bigger.
