Track 1

Hello, World (Awaken)

Opens with a lone, droning organ; the guitars crash in on the first print.

Intro, spoken

In the beginning there was the void… and a blinking cursor.

Verse 1

The screen is black, the cursor blinks,
The machine is waiting, it never thinks.
I type the words the elders knew,
print("Hello, World") — and the light breaks through!

Chorus

Hello, World! I am alive!
Run the code and watch it thrive!
One line of power, one line of fire,
The first command of the code-born choir!

Verse 2

Source to the compiler, compiler to the core,
Syntax errors scream at me, I fix them, run once more.
A semicolon missing brought the whole thing down,
But now my words are glowing and I wear the coder’s crown!

Chorus

Bridge

Input! Output! The sacred flow!
Keyboard above and the screen below!
Read what they give me, show what I know,
Instructions in order, row after row!

Outro

Hello… world… hello… world…

Lesson: a program is a list of instructions run in order. You write source code, the computer translates and runs it, syntax errors stop it before it starts, and input and output are how it talks to the world.

Track 2

Bound in Memory

Mid-tempo stomp, every line lands like a hammer on an anvil.

Verse 1

I carve a name upon a box of iron and of steel,
int score = 0; — the bargain’s sealed.
A variable’s a vessel with a name upon the door,
Assign it something new and the old is gone forevermore!

Chorus

Bound in memory! Name and value!
Bound in memory! Typed and true!
Int and double, boolean, char,
Know your type and you’ll go far!

Verse 2

An int holds the whole ones, no fraction can it keep,
A double holds the decimals that wander through the deep,
A boolean knows only true or false, the day or night,
A char is one lone letter, and a String’s a word of might!

Chorus

Bridge

Seven divided by two! (Is three!)
Integer division throws the half away from me!
Cast it to a double if you want the point-five,
Or the truncation demon eats your fraction alive!

Outro

score = score + 1; … the box remembers.

Lesson: a variable is a named place that holds a value. Its type decides what it can hold, assignment replaces the old value, and integer division drops the fractional part.

Track 3

Truth Tables of Doom

Grinding, chromatic riff that only ever lands on two notes: true and false.

Verse 1

Plus and minus, times, divide, the ancient math of men,
Modulo hands back what’s left, again and yet again.
Precedence decides which blow will fall before the rest,
Parentheses will bend the order — use them when you’re pressed!

Chorus

True! False! The judgement falls!
And, or, not through the marble halls!
Both must be true for the AND to rise,
Just one for the OR, and the NOT turns lies!

Verse 2

Double equals asks a question, single equals takes,
Mix them up, oh wretched one, and feel the code that breaks!
Less than, greater, not equal — comparisons of steel,
They forge the truth that every branch and every loop will feel.

Chorus

Bridge

Short circuit! (Short circuit!)
If the first is false, the AND won’t see!
Short circuit! (Short circuit!)
If the first is true, the OR goes free!

Outro

Not true… is false… is false…

Lesson: arithmetic operators (including % for remainder) follow precedence rules; == compares while = assigns; &&, || and ! combine conditions, and they stop early once the answer is known.

Track 4

The Crossroads of Logic

Thunderous drums, a riff that splits into two guitars at every fork.

Intro, spoken

Every program reaches the crossroads… and it must choose its path.

Verse 1

I stand at the fork where the dark roads divide,
if the condition is true, I go to one side.
else I take the other, there’s no in-between,
True or false, the sharpest blade you’ve seen!
else if, else if, I can chain them in a row,
Checking every gate till I know where to go!

Chorus

Decide! Decide! The branches are calling!
One path is rising, the other is falling!
Test it with if or switch on the sign,
The program obeys, the choice is divine!

Verse 2

When the question is a range, like greater than ten,
When AND meets OR in the battle again,
When the truths are tangled and they can’t be named,
if is the hammer that won’t be tamed!

Verse 3

Now the switch is a judge with a single decree,
He takes one value and he sets it free.
Case one, case two, case three in a row,
He jumps to the match and he lets it go!
And the default waits when no case is true,
The last line of defense standing guard over you!

Bridge

Fall through! (Fall through!) Forgot to break the line!
Fall through! (Fall through!) Now you’re running every case in time!
Put your break at the end of the deed,
Or the cases will bleed, the cases will bleed!

Final chorus

if for the ranges! if for the twisted and the true!
Switch for one value with exact cases to see you through!
Decide! Decide! The branches are calling!
The program obeys, or the program is falling!

Lesson: use if/else if/else for ranges and compound conditions; use switch when one value is compared against many exact options. In classic switch syntax, a missing break falls through to the next case.

Track 5

Iron Iteration

Slow, doom-laden riff in E, then it gallops.

Intro, spoken over feedback

In the depths of the machine, where the instructions never sleep… there are three ways to repeat.

Verse 1

I know where I’m starting, I know where I’ll end,
A counter in my fist from one up to ten.
for i = 1, and I march down the line,
Each step is numbered, each step is mine!
When the count runs out, I break from the chain,
I know how many times I’ll ride through the pain!

Chorus

Loop! Loop! Around and around!
The code keeps on turning, it’s iron-bound!
Count it, or check it, before or behind,
Iteration is burning a hole in my mind!

Verse 2

Now the while is a watchman who stands at the gate,
He checks the condition before you can wait.
While the fire is burning, he lets you inside,
But if it’s already false, you’ll never ride!
Zero times or forever, he won’t say which,
Forget to change the test and you’re stuck in the ditch!

Chorus

Bridge

Infinite loop! (Infinite loop!) No way out of the hall!
Infinite loop! (Infinite loop!) Forgot to update it all!
Change the variable, break the spell,
Or spin forever in silicon hell!

Verse 3

Repeat until: the reckless one,
He charges through the door before the test is done.
He does the deed once, then he asks the question,
Until the dragon’s dead, no hesitation!
At least one time he’ll swing the blade,
The check comes after the move is made!

Final chorus

For when you know the number!
While when you check before!
Repeat until you’ve done it once,
Then test it at the door!

Lesson: for when the number of repetitions is known; while tests first and may run zero times; repeat-until (do-while) tests last and always runs at least once. Something inside the loop must move it toward stopping.

Track 6

Call of the Function

Call-and-response anthem; the crowd shouts back every “Call!”

Verse 1

Don’t write it twice, don’t write it thrice, the wise ones always say,
Wrap the deed inside a name and call it any day.
Define the ritual, give it parameters to hold,
Pass arguments into the gate and watch the spell unfold!

Chorus

Call! (Call!) The function answers!
Call! (Call!) It does the deed!
Takes what you give and returns what you need!
Call! Call! Call!

Verse 2

return sends the treasure back to the one who made the call,
A void one does its work and gives back nothing at all.
The variables inside it live and die within its walls,
That’s scope, my friend — what’s born inside, outside it never crawls!

Chorus

Bridge

Break it down! (Break it down!) Big problems into small!
Decompose! (Decompose!) And conquer them all!
Name it well and test it alone,
Each little function a stepping stone!

Outro

Return… return… return.

Lesson: functions (methods) package code under a name so it can be reused. Parameters are the placeholders, arguments are the actual values passed in, return hands a result back, local variables only exist inside, and big problems get broken into small functions.

Track 7

Chains of Characters

Side B opens with clanking chains and a twin-guitar harmony line.

Verse 1

Letters bound together in a chain of shining links,
A String’s a row of characters, it’s more than you think.
charAt reaches in and pulls a single letter out,
length counts up every link, from the whisper to the shout!

Chorus

Chains! Chains of characters!
Concatenate and bind!
Plus will forge them into one,
Link by link aligned!

Verse 2

substring cuts a piece away — the start is kept, the end is not,
Remember that, or lose the final letter that you got!
Compare them with .equals, never with the double sign,
Or you’re checking where they live, not the words upon the line!

Chorus

Bridge

Immutable! (Immutable!) The chain can never change!
Every edit forges new, the old one stays the same!
Uppercase, replace, or trim the ends,
You get a brand new chain, my friends!

Lesson: a string is a sequence of characters, indexed from zero. + joins strings, substring(start, end) excludes the end index, Java strings are compared with .equals rather than ==, and string methods return new strings instead of changing the original.

Track 8

Index of Doom

Funeral-march tempo that counts out every slot, starting from zero.

Verse 1

A row of iron coffins lined up in the night,
One name to rule them all, each slot sealed tight.
The first one is the zero, don’t you dare forget,
The count begins at nothing — it’s the oldest debt!

Chorus

Index! Index! Zero to n minus one!
Index! Index! Till the array is done!
Square brackets open the coffin lid,
a[i] reveals what the darkness hid!

Verse 2

Walk it with a for loop from the zero to the end,
length tells you just how far the march will extend.
An array is fixed in size, the coffins cannot grow,
But a list will stretch and swallow more — add and watch it go!

Chorus

Bridge

Out of bounds! (Out of bounds!) Index n is not there!
Out of bounds! (Out of bounds!) The exception rips the air!
Off by one, off by one,
The curse of every coder’s son!

Outro

Zero… one… two… n minus one… (silence)

Lesson: an array stores many values under one name, indexed from 0 to length − 1. Arrays have a fixed size; lists (like ArrayList) can grow. Using index length or beyond crashes, and off-by-one errors are the classic loop bug.

Track 9

Blueprint of the Beast

Epic, galloping, with a choir of identical voices that slowly drift apart.

Verse 1

In the forge of the class the blueprint’s drawn in fire,
Fields to hold its memory, methods for its ire.
But the blueprint’s not the beast, it’s just the plan, the mold,
new breathes life into the iron, makes the object bold!

Chorus

Blueprint of the beast!
One class, a thousand forms!
Each object holds its own state
Through the raging storms!

Verse 2

The constructor is the birth rite, sets the fields when life begins,
this speaks of the object’s self, what lies within its skin.
Keep your fields private, guard them with your might,
Let the methods be the gatekeepers — encapsulation’s right!

Chorus

Bridge

Instance! (Instance!) Two dragons from one mold!
Instance! (Instance!) One is young and one is old!
Same methods, different fire,
Each one burns with its own desire!

Lesson: a class is a blueprint; objects are instances made with new. Fields hold each object’s own state, methods define its behavior, the constructor sets it up, this refers to the current object, and private fields with public methods give you encapsulation.

Track 10

Bug in the Machine

Paranoid, skittering riff; the drums keep dropping out like something’s wrong.

Verse 1

It compiled without a warning, but the answer’s wrong,
Something’s crawling in the shadows where it don’t belong.
Syntax was the easy foe, the compiler shows its face,
But logic bugs are phantoms and they never leave a trace!

Chorus

Bug in the machine! Hunt it down!
Print the values, trace the ground!
Read the error, find the line,
Test it till the output’s fine!

Verse 2

Read the stack trace like a map that leads you to the lair,
Set a breakpoint, step by step, the debugger takes you there.
Predict before you run it, then compare what came to be,
The gap between expected and the actual sets you free!

Chorus

Bridge

Test the edges! (Test the edges!) Zero, empty, negative one!
Test the edges! (Test the edges!) Before your work is done!
The biggest and the smallest and the one that isn’t there,
That’s where the bugs are breeding, so beware!

Outro

Explain it to the rubber duck… the duck knows… the duck always knows.

Lesson: syntax errors are caught before running, runtime errors crash with a stack trace, and logic errors give wrong answers quietly. Debug by predicting the output, printing or stepping through values, and testing edge cases.

Track 11

Sorting the Damned

Starts chaotic and atonal, and the riff literally falls into order by the last chorus.

Verse 1

Searching through the darkness, one by one I walk the line,
Linear search checks every soul until the target I find.
But if the list is sorted, cut the realm in half,
Binary search divides and laughs the conqueror’s laugh!

Chorus

Sort them! Sort the damned!
Order from the chaos by my hand!
Swap them! Compare them!
Smallest to the front of the land!

Verse 2

Selection finds the smallest, drags it to the front,
Insertion slides each newcomer in, a careful hunt,
Bubble swaps the neighbors till the giants reach the skies,
Slow but true — n squared beneath the burning skies!

Chorus

Bridge

Big O! (Big O!) How the time will grow!
n for the linear, walking slow!
Log n for the halving blow!
n squared when the sorts are slow!

Lesson: linear search checks each item (time grows with n); binary search halves a sorted list each step (log n). Selection, insertion and bubble sort are simple but take about n² comparisons. Big-O describes how running time grows with input size.

Track 12

Base Case

Eight-minute closer: each verse is a little shorter than the last, until it hits bottom and climbs back out.

Verse 1

A function that calls itself, a mirror in a mirror’s eye,
Each call a smaller problem as the stack climbs high.
Factorial of n is n times factorial of n minus one,
Down and down the spiral till the smallest case is done!

Chorus

Base case! The floor of the abyss!
Base case! Without it, nothing but this!
Every step must shrink the fight,
Till the base case brings the light!

Verse 2

Then the calls return like warriors home from war,
Each one hands its answer back to the one that came before.
The stack unwinds in glory, frame by frame by frame,
And the first call holds the answer, and we speak its name!

Chorus

Bridge

Stack overflow! (Stack overflow!) No base case in sight!
Stack overflow! (Stack overflow!) Falling through the endless night!

Final chorus

From Hello, World to the base case low,
We counted, we branched, we let the loops go!
Every step must shrink the fight,
Till the base case brings the light!

Outro, spoken

And so the student becomes the programmer… and types, once more… Hello, World.

Lesson: a recursive function solves a problem by calling itself on a smaller version. It needs a base case that stops the recursion and each call must move toward it; otherwise the call stack overflows. Results are built up as the calls return.
